Sorting Visualizer

An interactive web application that visually demonstrates the inner workings of popular sorting algorithms. This tool is designed to help learners and enthusiasts understand how each algorithm manipulates data step by step.

Project Overview

This application provides visual representations of various sorting algorithms, allowing users to observe and comprehend the process each algorithm follows to sort data. The visual cues and controls enhance the learning experience by making abstract concepts more tangible.

Features

Implemented Algorithms:

  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - Merge Sort
  - Quick Sort
  - Heap Sort

Color-Coded Visualization:

  - Blue: Default state
  - Yellow: Elements being compared
  - Red: Elements identified as in the incorrect position and to be moved
  - Green: Elements in the correct position

User Controls:

  - Adjustable speed of visualization
  - Array size selection
  - Choice of sorting algorithm

Repository Structure

* `index.html`: Main HTML file that structures the web page.
* `style.css`: Styling for the application.
* `main.js`: Handles user interactions and integrates sorting algorithms with the visualization.
* `visualization.js`: Manages the visual representation of the sorting process.
* `bubblesort.js`, `selectionsort.js`, `insertionsort.js`, `mergesort.js`, `quicksort.js`, `heapsort.js`: Individual files implementing each sorting algorithm.

Technologies Used

Frontend:
  - HTML
